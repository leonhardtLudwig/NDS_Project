\begin{abstract}
% ADDED (2026-11-03): abstract.
A stubborn agent, which never changes its opinion, is the extreme case of two different
mechanisms of resistance to social influence: a self-weight in the
French--Harary--DeGroot (FDG) model and an attachment to a fixed prejudice in the
Friedkin--Johnsen (FJ) model. Following the tutorial by Proskurnikov and Tempo, this
report compares the two models on the same small networks and studies how these
mechanisms affect convergence, the final opinions and the influence of each agent,
measured by the social power and by the influence centrality. A self-weight acts as
inertia: it slows an agent down, makes the network aperiodic and earns influence
gradually. A prejudice acts as an anchor: a single prejudiced agent reached by everybody
makes the FJ model asymptotically stable and takes the whole influence centrality, while,
when every agent is prejudiced, different prejudices keep the group divided on any
network. Writing the FJ model as an FDG model on an augmented graph, with the prejudices
as virtual stubborn agents, shows that the two models differ in what is a state: the
opinion of a stubborn agent is a memory inside the state in the FDG model and an external
input in the FJ model.

% Abstract.
\end{abstract}
